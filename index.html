HELP CENTER

Frequently asked questions

Are my PDFs uploaded to a server?

No. The tools in this first version process selected PDF and image files in your browser. The app downloads its JavaScript libraries from public CDNs, but it does not send your selected documents to an Eaziply processing server.

Does Eaziply need an API key or an account?

No API key, database, account or custom backend is required. The static website is designed for GitHub and Vercel hosting. Internet access is required to load the app and its CDN libraries.

Can I save and reuse my signature?

Yes. In Sign PDF, type, draw or upload your signature and choose “Save this signature”. It is stored in this browser on this device, so you can select it again on future visits. You can delete saved signatures from the same controls. Do not save a signature on a shared or untrusted device.

Can I see every PDF page and jump to an exact page?

Yes. In Sign PDF and Fill & add text, pages appear in a continuous vertical view. The page control (for example, 1 / 33) stays available; type a page number and press Enter to jump directly to it. Scrolling also updates the current page number.

Can I edit text already inside a PDF?

Eaziply can add new editable text boxes. For existing text, the “Cover old text” option places a white patch behind replacement text; it does not rewrite the original PDF text layer and may cover nearby lines or images. It works best on plain white areas.

Can I add a handwritten-style signature?

Yes. In Sign PDF, type a name and choose a style, draw with your mouse or touch screen, or upload a transparent signature image. Place it on any page, drag or resize it, and download the entire edited PDF. A visible signature is not the same as a certificate-based digital signature.

Will compression always make my PDF smaller?

No. Basic optimization rewrites the PDF using object streams, but it does not aggressively re-compress every embedded image. The resulting file may be smaller, similar in size, or occasionally larger.

Does Eaziply convert PDFs to editable Word or Excel files?

Not in this first version. High-quality Office conversion and OCR for scanned documents require more specialized processing and testing. We prefer to show only tools that are actually implemented.

Is an electronic signature legally valid?

Rules and acceptance vary by document, recipient and jurisdiction. Eaziply places a visible signature image; it does not independently verify identity or apply a certificate-based cryptographic digital signature.
